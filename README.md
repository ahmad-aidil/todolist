#Aplikasi To-Do List

##Deskriptif
Aplikasi sederhana berbasis PHP untuk mencatat tugas harian.
Tugas ditambah dengan mengisi pada laman form lalu mengklik tambah untuk tugasnya ditambahkan ke dalam table.
Setelah ditambahkan dan akan muncul record atau baris yang berisi nama tugas serta ada pilihan aksi untuk menceklis misalkan
apakah tugas tersebut selesai atau belum, dan juga dapat menghapus tugas yang sudah selesai pada tiap baris tugas.
Kemudian jika kemudian untuk merubah nama tugas yang sudah ditambahkan atau dicreate maka bisa memilih untuk edit tugas, lalu merubah nama tugas.

##Fitur
Tambah Tugas
Menandai Tugas sebagai Selesai
Edit Nama Tugas
Hapus Tugas

##Struktur Folder
- `koneksi.php` - konek Database
- `index.php` - halaman Utama
- `assets` - file CSS/JS

##Cara menjalankan
1. salin folder todolist ke `/xampp/htdocs/`
2. jalankan XAMPP, hidupkan apache dan mysql dan buka di `localhost/todolist`
